# 界面与交互规范

适用于项目、资料、要求核对、填写建议、证据及模型设置。样式定义以 `src/theme.ts` 为准，共用组件位于 `src/components/Workspace.tsx`。

## 视觉

- 保留砖红主色 `#B7432B`，用于当前导航、主要操作与关键定位；深色文字 `#202939`，次级文字 `#667085`。
- 画布 `#F6F7F9`，内容面板白色，边线 `#E4E7EC`。使用边线区分层次，减少大面积阴影和装饰渐变。
- 绿色表示完成或核实，黄色表示补充或复核，红色表示失败或不符合，蓝色表示正在处理。状态同时提供中文文字。
- 系统正文使用 Avenir Next / 苹方等无衬线字体，正文 14px，辅助正文 13px，说明 12px，页面标题约 26px，区块标题 16px。
- 间距以 8px 为基础；面板内边距 20px，区块间距 24px；圆角 8px，按钮高度至少 36px。

## 导航与流程

- 桌面固定侧栏 224px；小屏使用抽屉菜单。当前项目的子菜单提供资料、要求、填写、检查、证据与历史分析入口。
- 顶部面包屑显示“项目 / 项目名称 / 当前页面”，父级可点击返回。
- 业务流程固定为“准备资料 → 核对要求 → 填写建议 → 检查导出”。切换页面不代表该步已经完成。
- 工作台页签写入 URL 查询参数，刷新、侧栏和浏览器返回保持一致。
- 每页使用 `PageHeader`；需要指导时使用 `Guidance`，说明当前任务及完成后的结果。

## 常规操作

- 列表提供搜索、状态筛选和操作列。项目列表分页；文件可查看原文、下载、编辑用途或移除。
- 新建后进入下一步，例如创建项目后进入资料准备。保存成功提供反馈；失败显示原因及恢复路径。
- 表单使用中文字段名，标识必填与选填；内部 ID 和字段标识不交给客户输入。
- 编辑时回填原值；密钥留空表示沿用。保存配置不自动测试，不触发模型请求。
- 删除使用统一确认对话框，说明对象、影响范围及不可撤销；被引用文件需要先处理关联记录。
- 空状态说明为什么为空及下一步，并提供真实可用的按钮。加载和失败不显示为业务空状态。

## 可访问性与响应式

- 交互控件使用按钮或链接，提供可见焦点、标签和选中状态；保留“跳到主要内容”入口。
- 表单控件有标签；图标按钮有说明。删除确认、表单和帮助抽屉可关闭。
- 小屏表单与工作区域纵向排列，表格在自身容器内滚动；页面不产生整体横向溢出。
- 尊重减少动态效果的系统偏好。操作指南随时可打开，不使用阻塞式引导弹窗。
